# PaperProof 竞品分析

> 调研日期：2026-10-22  
> 说明：以下为公开网页信息整理，正式参赛前需对关键产品做实际试用和截图留证。

## 一、结论

“论文引证核验”不是空白市场。直接竞品已经能够：

- 拖入 Word 草稿；
- 逐条核验引文与论断是否一致；
- 读取完整原文；
- 分类为支持、不支持、夸大、矛盾、无法验证；
- 给出修改建议；
- 面向个人、大学、出版商和基金机构。

因此不能把“拖入论文 + 检查引用”本身当作创新点。需要寻找更窄、更深、更难复制的场景。

## 二、直接竞品

### 1. Jenni AI — Claim Confidence

链接：https://jenni.ai/zh/reviews/ai-citation-checker

能力：

- 拖入 DOCX 或粘贴章节；
- 读取正文中的引用；
- 对照文献库、CrossRef、PubMed、OpenAlex；
- 读取完整源内容；
- 七类判定：支持、误传、矛盾、不支持、弱支持、夸大、无法验证；
- 显示原文段落和建议改写；
- 同时提供同行评审、语言校对等功能。

竞争威胁：非常高。产品成熟度和工作流最接近“拖稿即审”。

### 2. CiteWise

链接：https://citewise-ai.com/

能力：

- 检查每条 claim 是否被引用证据支持；
- 提出最小修正建议；
- 检查撤稿、找不到来源、错误引用；
- 面向研究人员、出版商、大学、基金机构；
- 强调隐私，不用于模型训练。

竞争威胁：非常高。已经覆盖个人和机构市场，并把“引用存在不等于引用正确”作为核心叙事。

### 3. SemanticCite

链接：https://semanticcite.com/

能力：

- 分析完整来源文档；
- 验证论断是否准确反映引用材料；
- 学术引用验证平台。

竞争威胁：高。技术路线与 RAG + 全文核验高度重合。

### 4. Cento

链接：https://cento-research.com/

能力：

- 面向医学研究写作；
- 将 claim 与 source 长期绑定；
- 在修改过程中重新评分证据支持程度；
- 检测 citation drift（引证漂移）；
- 目前以眼科和 early access 为切入点。

竞争威胁：中高。虽然细分领域较窄，但“版本修改中的引证漂移”已经被产品化。

### 5. 参考文献真实性工具

- Citely：https://citely.ai/zh/citation-checker
- Check Your Draft：https://checkyourdraft.com/zh/citation-checker
- AccuraCite：https://accuracite.com/
- Resea：https://resea.ai/zh/cite-checker

能力：

- 验证 DOI、作者、标题、期刊；
- 检测虚假引用和 AI 幻觉引用；
- 检查撤稿状态；
- 部分产品提供与 claim 相关的引用推荐。

竞争威胁：中。它们主要验证“文献是否真实”，不一定验证“文献是否支持这句话”。

## 三、中文学位论文格式与盲审类产品

### 1. PaperPass 论文格式检测

链接：https://www.paperpass.com/format-check

能力：

- 选择学校模板；
- 上传 Word；
- 检查论文格式规范；
- 生成检测结果。

### 2. 格子达

链接：https://gocheck.cn/

能力：

- 论文查重；
- 格式检测；
- 格式校正；
- 面向高校服务。

### 3. 论文智检

链接：https://readypaper.cn/

能力：

- 上传 DOCX；
- 错别字、病句、图片、表格、参考文献检查；
- 面向学位论文、期刊投稿、机构审核、导师指导；
- 宣称支持多维度学术规范检测。

竞争威胁：高。产品叙事已经覆盖“学位论文规范自查和导师指导”。

### 4. 格式无忧

链接：https://doctrust.cn/Home/Online

能力：

- 支持高校模板；
- 检查论文格式错误；
- 在线和线下生成报告。

竞争威胁：中高。聚焦格式与规范，尚未明显覆盖全文证据核验。

### 5. WPS 智能文档 / 黑马校对

链接：

- https://365.wps.cn/content/fd214b7a39f1439ab7ec645ed6d6b5eb.html
- https://365.wps.cn/content/1300b4e04646420b8953d8a7cb05853b.html

能力：

- 学位论文自动排版；
- GB/T 7714 参考文献检测；
- 学术术语规范；
- 批量智能校对；
- 与 Word/WPS 写作环境深度结合。

竞争威胁：非常高。平台级厂商一旦增加“证据核验”，会形成强竞争。

## 四、文献发现、写作与引用语境产品

| 类型 | 产品 | 主要能力 |
|---|---|---|
| 文献发现与综述 | Elicit | 检索、筛选、提取、系统综述 |
| 文献阅读与问答 | SciSpace | 论文阅读、问答、文献综述 |
| 科学问答 | Consensus | 基于论文回答问题 |
| 引文语境 | scite | 判断引用是支持、对比还是提及 |
| 学术写作 | Jenni、Paperpal、Writefull | 写作、改写、润色 |

| 查重 | Turnitin、iThenticate、知网 | 文本相似度和学术不端检测 |

## 五、竞争格局判断

### 已经拥挤的赛道

1. 通用 AI 论文写作；
2. 参考文献真实性和 DOI 检查；
3. 单篇论文的 claim-citation 核验；
4. 中文学位论文格式检测；
5. 查重和 AIGC 检测。

### 尚未被充分覆盖的方向

不是“再做一个引用检查器”，而是以下组合：

> **本地私有文献库 + 中文/英文混合论文 + 多轮版本修改 + 导师审稿工作流。**

更具体的方向：

> **版本级引证审计：监控论文每一次修改，检测哪些新论断没有证据、哪些引用在修改后发生漂移、哪些结论被 AI 润色后说过头。**

## 六、建议的差异化定位

### 产品定位

> PaperProof：面向科研课题组的本地论文版本引证审计软件。

### 核心差异

1. **版本感知**
   - 不是只审一版，而是比较 v1、v2、v3；
   - 找出“修改后新增的无证据强结论”；
   - 检测 citation drift。

2. **课题组本地文献库**
   - 不是只查公开数据库；
   - 支持实验室内部 PDF、未公开论文和项目材料；
   - 本地运行，不上传云端。

3. **中文论文深度适配**
   - 中英文混排；
   - GB/T 7714；
   - 中文学位论文结构和匿名信息检查；
   - 未来支持 WPS/Word。

4. **导师审稿报告**
   - 不是面向个人的泛写作工具；
   - 直接输出导师可看的风险清单和修改摘要；
   - 形成课题组审稿流程。

## 七、风险

- Jenni、CiteWise 等全球产品可能继续增加版本比较；
- Cento 已经在做 citation drift；
- WPS、PaperPass、格子达可能向证据核验扩展；
- 本地部署和机构销售需要更多工程与合规工作；
- 中文全文证据核验需要自建评测集。

因此，产品必须尽快形成：

- 课题组本地数据；
- 版本历史；
- 导师审稿工作流；
- 中文学术规范；
- 可量化评测结果。

## 八、下一步调研

1. 注册并实测 Jenni Claim Confidence、CiteWise、SemanticCite；
2. 记录它们是否支持中文、DOCX、本地 PDF、版本比较、GB/T 7714；
3. 实测 PaperPass、论文智检、WPS 黑马校对；
4. 访谈 3-5 名研究生和 1-2 名导师；
5. 根据真实缺口决定最终定位。
